# 游戏概念总览 (Game Concept Overview)

## 项目名称
**MHBG-A350** — 怪物猎人灵感的飞行途中手机离线游戏

---

## 核心定位

| 项目 | 描述 |
|------|------|
| **目标平台** | 手机浏览器（HTML5 / PWA，完全离线可运行） |
| **目标玩家** | 乘坐飞机、无网络连接的旅客 |
| **灵感来源** | 怪物猎人系列（Monster Hunter） |
| **核心体验** | 短时间内可完成的回合制战斗，策略性武器使用 |
| **单局时长** | 约 10–20 分钟 |

---

## 游戏世界观（Flavor）

玩家是一名猎人，在飞行途中（真实场景呼应）偶遇迷途的远古龙兽。  
你的任务：在降落前打倒它，或至少将它击退。  
武器和技能都是旧世界的猎人传统，简单而有力。

## 核心机制概述

### 1. 战场布局

```
┌─────────────────────────────┐
│           BOSS              │
│  [ 正面 | 侧面 | 背面 ]     │
│   front   side   back       │
└─────────────────────────────┘
         ↓ Boss 朝向
┌───────────────┐
│  1-1 │ 1-2 │ 1-3 │  ← 第一排（近战前线）
│  2-1 │ 2-2 │ 2-3 │  ← 第二排（中距离）
│  3-1 │ 3-2 │ 3-3 │  ← 第三排（远程 / 安全区）
└───────────────┘
     玩家站位（3×3 方格）
```

- 战场分为 **Boss 面朝的正面、侧面、背面**，不区分左右侧  
- 玩家可选 3×3 共 9 格站位  
- 排数（Row）决定与 Boss 的距离，影响武器射程判定

### 2. Boss 部位系统

| 部位 | 说明 |
|------|------|
| **头部 (Head)** | 初始锁定，可受部位特效 |
| **四肢 (Limbs)** | 共享一个「击破条」，击破后解锁其他弱点 |
| **背部 (Back)** | 四肢击破后可攻击 |
| **尾部 (Tail)** | 四肢击破后可攻击；击破尾部可降低横扫频率 |

> **击破机制**：四肢共用一个击破进度条。当进度条清空，四肢被击破，Boss 进入倒地状态（若干回合），此期间背部、尾部均可作为攻击目标。

### 3. Boss 行动逻辑（每回合 Roll 点）

Boss 每回合掷骰决定行动：

| 骰子结果 | 行动名称 | 效果 |
|----------|----------|------|
| 1–3 | **甩尾横扫** | 对**第一排**所有玩家格造成伤害 |
| 4–6 | **吐息攻击** | 对某**一列**（1、2 或 3 列）所有玩家格造成伤害 |

> 后续版本可扩展 Boss 技能表，加入更多行动类型。

### 4. 骰子攻击系统

- **基础骰子数量：2**  
- 玩家每次攻击掷骰，骰子点数之和为伤害（或命中判定，由方向决定）  
- 武器特有资源可在攻击时消耗，额外增加骰子  
- 骰子数量越多，期望伤害越高，但资源有限需合理管理

### 5. 玩家回合结构

```
[ 玩家回合 ]
  ├── 移动阶段（可跳过）
  │     └── 选择移动至相邻一格（上/下/左/右，不可斜）
  └── 攻击阶段
        ├── 选择攻击目标（Boss 部位）
        ├── 选择是否消耗武器资源增加骰子
        └── 掷骰 → 结算伤害
```

### 6. 武器选择

玩家在游戏开局选择一把武器，武器决定：
- **特有资源类型**（弹药、蓄力值、连击层数等）
- **技能与骰子增益方式**
- **攻击有效距离**

## 两个开发方向概览

| 方向 | 名称 | 核心差异 |
|------|------|----------|
| **方向一** | 基础回合制 | 直接掷骰攻击，资源管理驱动，策略重在站位与武器技能时机 |
| **方向二** | 卡牌回合制 | 武器技能以「手牌」形式呈现，每回合抽取并使用卡牌，增加组合与构筑感 |

## 技术约束（飞行模式考虑）

- 纯 HTML5 + JS，**无需网络**
- 本地存储（localStorage）保存进度，防止意外关页
- 不依赖任何 CDN 资源
- 适配竖屏手机，操作以点触为主，无需复杂手势
- 首次加载后完全离线可用（PWA Service Worker 缓存）
