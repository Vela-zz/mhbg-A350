# 方向一：基础回合制战斗 (Direction 1 — Core Turn-Based Combat)

## 设计目标

提供一个**直接、低学习曲线**的回合制战斗体验。  
玩家专注于站位决策、武器资源管理与攻击时机，操作界面简洁，适合碎片化时间游玩。

---

## 完整回合流程

```
═══════════════════════════════════════
         一个完整游戏回合
═══════════════════════════════════════

[1] Boss 行动阶段
    └─ Boss 掷 1d6
       1–3 → 甩尾横扫（第一排所有格受击）
       4–6 → 吐息攻击（随机选择列 1/2/3 全列受击）
       → 计算对站于受击格玩家的伤害

[2] 玩家移动阶段（可跳过）
    └─ 选择移动至相邻格（上/下/左/右）
       或宣告「跳过移动」

[3] 玩家攻击阶段
    ├─ 选择攻击 Boss 部位：
    │   头部 / 四肢 / 背部（需四肢击破）/ 尾部（需四肢击破）
    ├─ 选择是否消耗武器资源增加骰子
    └─ 掷骰（基础 2d6 + 额外骰子）→ 结算伤害 / 击破进度

[4] 状态更新
    ├─ 检查四肢击破条 → 若归零进入「倒地」状态
    ├─ 检查 Boss 血量 → 若归零判定胜利
    └─ 检查玩家 HP → 若归零判定失败

```

## 战场与站位规则

### 3×3 站位网格

```
列  →   1       2       3
排 ↓ ┌───────┬───────┬───────┐
 1   │ [近] │ [近] │ [近] │  ← 距离 1（与 Boss 最近）
     ├───────┼───────┼───────┤
 2   │ [中] │ [中] │ [中] │  ← 距离 2
     ├───────┼───────┼───────┤
 3   │ [远] │ [远] │ [远] │  ← 距离 3（与 Boss 最远）
     └───────┴───────┴───────┘
```

- **排号**即为该格的「距离值」
- 武器攻击有最大有效距离，当玩家所在排号 ≤ 武器距离时方可造成伤害  
  例：大剑距离 1 → 只有第一排（排号=1）时有效

### 移动规则

- 每回合移动阶段可向相邻一格（上/下/左/右，不含斜向）移动一次  
- 不可移出 3×3 边界  
- 可宣告跳过（保留站位）

## 攻击与骰子系统

### 基础流程

1. 玩家选择攻击目标部位  
2. 决定是否消耗武器资源（增加额外骰子）  
3. 掷骰：`基础 2 个骰子 + 额外骰子`  
4. 所有骰子点数之和 = 本次攻击伤害（或击破进度值）

### 距离失效

若玩家当前排号 > 武器最大距离，本次攻击**无效**（掷骰结果归零）。  
这意味着近战武器玩家必须主动移至前排承担更高风险。

## Boss 部位 & 击破系统

| 部位 | 初始可攻击 | 击破后效果 |
|------|-----------|-----------|
| 头部 | ✅ | — |
| 四肢 | ✅（共享击破条） | 击破 → 解锁背部 & 尾部；Boss 进入倒地（2 回合） |
| 背部 | ❌（需四肢击破） | 背部受击倍率高，可触发特殊效果 |
| 尾部 | ❌（需四肢击破） | 击破尾部 → Boss 甩尾横扫概率下降（1–2 → 仅 1 触发横扫） |

### 倒地状态

- 四肢击破后 Boss 倒地持续 **2 个完整回合**  
- 倒地期间：Boss 不执行行动阶段，背部/尾部均可被攻击  
- 倒地结束：Boss 重新站立，背部/尾部重新锁定（但尾部击破状态永久保留）

## 武器系统

### 武器属性一览

| 属性 | 说明 |
|------|------|
| **最大距离** | 玩家排号需 ≤ 此值才能造成伤害 |
| **资源类型** | 武器独特资源（如弹药、蓄力值） |
| **资源上限** | 最大可持有量 |
| **资源恢复** | 每回合自然恢复量 / 条件恢复 |
| **技能消耗** | 消耗资源可额外增加的骰子数量 |

### 大剑（参考模板）

详见 [`weapons/greatsword.md`](./weapons/greatsword.md)

### 铳枪（参考示例）

| 属性 | 值 |
|------|-----|
| 最大距离 | 1（普通射击） / 2（炮击） |
| 资源 | 弹药（最多 4 发） |
| 资源恢复 | 每回合恢复 1 发 |
| **技能 A**：消耗 1 弹药 | +1 骰子 |
| **技能 B**：消耗全部 4 弹药 | +3 骰子（全弹发射） |

> 铳枪可在排号 ≤ 1 时普通射击，排号 ≤ 2 时可用炮击技能。

|------|------------|

| 四肢击破条 | 20 |

| 甩尾横扫基础伤害 | 4 |

## 胜负条件

| 条件 | 结果 |
|------|------|
| Boss HP = 0 | **胜利** |
| 玩家 HP = 0 | **失败** |
| （可选）回合上限到达 | 失败（Boss 逃脱） |

## 方向一的优势 & 挑战

### 优势
- 规则简洁，新玩家上手快
- 骰子随机性带来紧张感，操作决策明确
- 开发工作量相对较小

### 挑战
- 单局后期可能产生重复感
- 深度较浅，高手玩家可能较快失去新鲜感
- 需通过更多武器类型和 Boss 技能扩充内容
