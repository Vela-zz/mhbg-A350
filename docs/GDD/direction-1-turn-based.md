# 方向一：基础回合制战斗 (Direction 1 — Core Turn-Based Combat)

## 设计目标

提供一个**直接、低学习曲线**的回合制战斗体验。  
玩家专注于 AP 分配、站位决策、武器蓄力与攻击时机，操作界面简洁，适合碎片化时间游玩。

---

## 行动点数系统（Action Points, AP）

每回合每名猎人持有 **3 AP**，所有行动均消耗 AP：

| 行动 | AP 消耗 | 说明 |
|------|---------|------|
| **移动** | 1 AP / 格 | 移动至相邻格（上下左右） |
| **普通攻击** | 1 AP | 武器基础攻击 |
| **技能攻击** | 2–3 AP | 强力技能（视武器而定） |
| **蓄力** | 1 AP | 积累蓄力层数（大剑专属） |
| **结束回合** | 0 | 主动放弃剩余 AP |

> **蓄力储存规则（大剑特有）：** 若玩家结束回合时仍有剩余 AP 未使用，剩余 AP 自动转化为蓄力层数（1 AP = 1 层，上限 3 层）。持有蓄力时，每回合最多移动 **1 格**。

---

## 完整回合流程

```
═══════════════════════════════════════
         一个完整游戏回合
═══════════════════════════════════════

[1] Boss 行动阶段
    └─ Boss 依当前状态执行行动
       （见雄火龙行为设计文档）

[2] 玩家行动阶段（3 AP 自由分配）
    ├─ 移动（1 AP/格）
    │   └─ 若持有蓄力 > 0，本回合最多移动 1 格
    ├─ 攻击 / 技能（1–3 AP）
    │   └─ 选择攻击目标：躯体 / 头部 / 翅膀 / 尾部
    ├─ 蓄力（1 AP，大剑）
    │   └─ 蓄力层数 +1（上限 3）
    └─ 结束回合（剩余 AP → 蓄力层数，大剑规则）

[3] 状态更新
    ├─ 检查部位击破条 → 若归零触发对应效果
    ├─ 检查 Boss HP → 若归零判定胜利
    ├─ 检查玩家 HP → 若归零判定失败
    └─ 检查 Boss 状态转换（普通 / 怒り / 疲弊 / 倒地 / 飞行）

```

## 战场与站位规则

### 3×3 站位网格

```
列  →   0       1       2
排 ↓ ┌───────┬───────┬───────┐
 0   │ [近] │ [近] │ [近] │  ← 距离 1（与 Boss 最近，近战有效区）
     ├───────┼───────┼───────┤
 1   │ [中] │ [中] │ [中] │  ← 距离 2
     ├───────┼───────┼───────┤
 2   │ [远] │ [远] │ [远] │  ← 距离 3（与 Boss 最远）
     └───────┴───────┴───────┘
```

- **排号（Row）** 即为距离值，武器有最大有效距离
- 大剑距离为 **1**，玩家必须位于排号 0 才能攻击
- 列号（Col）影响受 Boss 某些攻击命中的概率

### 移动规则

- 每消耗 1 AP，可移动 1 格（上/下/左/右，不含斜向）
- 不可移出 3×3 边界
- **持有蓄力时**：每回合最多移动 1 格（无论 AP 剩余多少）

## 攻击与骰子系统

### 基础流程

1. 玩家选择技能（确认 AP 是否足够）
2. 选择攻击目标部位（躯体 / 头部 / 翅膀 / 尾部）
3. 掷骰：骰子数量由技能与蓄力层数决定
4. 骰子总和 = 本次攻击伤害（或部位击破进度值）

### 距离失效

若玩家排号 > 武器最大距离，本次攻击**无效**（掷骰结果归零）。

## Boss 部位 & 击破系统

| 部位 | HP（参考） | 初始可攻击 | 击破效果 |
|------|-----------|-----------|---------|
| **头部** | 20 | ✅ | 头部攻击伤害加成 x1.2 |
| **翅膀（合计）**| 30 | ✅ | 双翼破坏 → Boss 倒地 2 回合；无法进入飞行状态 |
| **尾部** | 20 | ✅ | 尾部攻击频率降低；横扫伤害 -2 |
| **背部** | — | ❌（倒地解锁）| 受击倍率 x1.5 |

### 倒地状态

- 双翼击破后 Boss 倒地持续 **2 个完整回合**
- 倒地期间：Boss 不执行行动阶段，背部可被攻击
- 倒地结束：Boss 重新站立，背部重新锁定（翅膀击破永久生效）

## 胜负条件

| 条件 | 结果 |
|------|------|
| Boss HP = 0 | **胜利** |
| 玩家 HP = 0 | **失败** |
| （可选）回合上限到达 | 失败（Boss 逃脱）|

## 方向一的优势 & 挑战

### 优势
- AP 制提供清晰的「行动预算」感，策略决策直观
- 蓄力机制创造 risk/reward 博弈
- 规则简洁，新玩家上手快

### 挑战
- 需要精心调校 AP 数量与技能 AP 消耗的平衡
- 单局后期可能产生重复感，需靠 Boss 状态变化补充张力
- 近战武器需长期处于危险前排，UI 需让风险感清晰可见
