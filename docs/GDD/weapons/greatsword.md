# 武器：大剑 (Great Sword)

> 本文档作为所有武器设计的**基础模板**，其他武器应参照此格式进行撰写。

---

## 武器概述

| 属性 | 值 |
|------|-----|
| **武器名称** | 大剑（Great Sword） |
| **武器代码** | `GS` |
| **最大攻击距离** | 1（仅在第一排有效） |
| **资源类型** | 蓄力值（Charge） |
| **资源上限** | 4 点 |
| **资源起始量** | 0 点 |
| **资源恢复方式** | 普通攻击 +1；蓄力行动 +2 |
| **武器定位** | 高伤害近战，需要资源积累，爆发强但需暴露于危险前排 |

---

## 武器特色说明

大剑以**蓄力爆发**为核心机制：
- 玩家通过普通攻击或主动蓄力积累蓄力值（Charge）
- 积累到一定量后，释放「强斩」或「大力斩」，骰子数量大幅提升
- 大剑攻击距离为 **1**，玩家必须位于第一排（排号 = 1）方能造成伤害
- 站在第一排意味着承受 Boss 甩尾横扫的全部伤害风险，形成高风险高回报的博弈

---

## 蓄力值系统

```
蓄力值（Charge）: 0 ──► 1 ──► 2 ──► 3 ──► 4（上限）

获取方式：
  · 普通攻击（消耗 0 蓄力）→ +1 蓄力
  · 主动蓄力（跳过攻击）   → +2 蓄力

消耗方式（技能）：
  · 强斩：消耗 2 蓄力 → +2 骰子
  · 大力斩：消耗全部蓄力（最少 3）→ +（蓄力值 - 1）骰子
```

---

## 技能详解

### 方向一（基础回合制）版本

| 技能名称 | 资源消耗 | 额外骰子 | 条件 |
|----------|----------|----------|------|
| **普通斩击** | 0 蓄力（并获得 +1 蓄力） | 0（基础 2d） | 排号 ≤ 1 |
| **强斩** | 2 蓄力 | +2 骰子 | 排号 ≤ 1；蓄力 ≥ 2 |
| **大力斩** | 全部蓄力（≥ 3） | +(蓄力值 - 1) 骰子 | 排号 ≤ 1；蓄力 ≥ 3 |
| **主动蓄力** | — | — | 跳过攻击阶段，获得 +2 蓄力 |

**大力斩骰子对照表：**

| 蓄力值 | 大力斩骰子总数（基础 2 + 额外） |
|--------|-------------------------------|
| 3 | 2 + 2 = **4d** |
| 4 | 2 + 3 = **5d** |

> 大力斩是大剑的核心爆发技能，建议在 Boss 倒地时配合使用以最大化输出。

---

### 方向二（卡牌回合制）版本

大剑基础牌组（共 16 张）：

| 卡牌名称 | 类别 | 数量 | 效果描述 |
|----------|------|------|----------|
| **普通斩击** | 攻击牌 | 4 | 掷 2d6；获得 1 蓄力 |
| **蓄力** | 资源牌 | 3 | 获得 2 蓄力；不可与攻击牌同回合打出 |
| **强斩** | 攻击牌 | 3 | 掷 4d6；消耗 2 蓄力（需蓄力 ≥ 2） |
| **大力斩** | 特殊牌 | 2 | 掷 (2 + 蓄力 - 1)d6；消耗全部蓄力（≥ 3）；本回合不可再打牌 |
| **看破** | 强化牌 | 2 | 本回合攻击弱点部位时 +2 骰子 |
| **侧步** | 移动牌 | 2 | 移动至任意相邻格 + 获得 1 蓄力 |

**牌组设计思路：**
- 蓄力资源牌提供安全积累路线（但浪费打牌机会）
- 普通斩击在输出同时自然积累蓄力，节奏流畅
- 大力斩作为「终结技」，需要计划 2–3 回合前布局
- 看破 + 强斩 / 大力斩 = Boss 倒地时的最优爆发组合
- 侧步提供移动灵活性并顺带积累蓄力，符合「蓄力爆发」主题

## 策略建议（供测试参考）

### 典型行动序列（方向一）

```
回合 1：普通斩击（蓄力→1）
回合 2：主动蓄力（蓄力→3）
回合 3：大力斩（蓄力 3 全消耗）→ 掷 4 骰 → 伤害爆发
```

```
回合 1：普通斩击（蓄力→1）
回合 2：普通斩击（蓄力→2）
回合 3：强斩（消耗 2 蓄力）→ 掷 4 骰
```

### 风险点

- 大剑玩家必须长期处于第一排，甩尾横扫直接命中
- 建议在 Boss 预告横扫时主动撤退（移动至第二排），跳过本回合输出
- 倒地阶段是大力斩的最佳时机：Boss 无行动，可以安心输出
