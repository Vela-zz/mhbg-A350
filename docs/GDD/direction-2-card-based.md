# 方向二：卡牌回合制战斗 (Direction 2 — Card-Based Turn Combat)

## 设计目标

在方向一的回合制骨架上，引入**卡牌手牌系统**，将武器技能和行动以「卡牌」形式呈现。  
玩家每回合从武器牌组抽取手牌，组合使用卡牌执行行动，带来更强的策略深度与构筑感。

---

## 核心差异对比（vs 方向一）

| 项目 | 方向一（基础回合制） | 方向二（卡牌回合制） |
|------|-------------------|-------------------|
| 武器技能触发 | 消耗资源 → 增加骰子 | 打出对应卡牌执行效果 |
| 决策维度 | 站位 + 资源分配 | 站位 + 手牌组合 + 顺序 |
| 随机来源 | 骰子结果 | 骰子结果 + 抽牌随机 |
| 扩展性 | 新武器 / 新技能 | 新卡牌 / 新牌组 / 组合 Synergy |
| 学习成本 | 低 | 中等 |

---

## 卡牌系统基础

### 牌组结构

- 每种武器对应一个**基础牌组**（约 10–15 张）
- 游戏开始时洗牌，形成抽牌堆（Draw Pile）
- 每回合抽 **3 张**加入手牌（手牌上限 5 张）
- 使用过的牌进入弃牌堆（Discard Pile）
- 抽牌堆耗尽时，弃牌堆重新洗牌成为新的抽牌堆

### 卡牌分类

| 类别 | 说明 |
|------|------|
| **攻击牌** | 对 Boss 部位发动攻击，掷基础骰子 |
| **强化牌** | 本回合增加骰子数量，或添加特殊效果（如穿透、部位伤害加成） |
| **移动牌** | 替代移动阶段，可移动 1–2 格，或附带额外效果 |
| **资源牌** | 恢复 / 增加武器特有资源 |
| **特殊牌** | 触发武器招牌技能（高消耗、高收益） |

> 每回合玩家可打出的卡牌数量上限为 **2 张**（可通过特定卡牌效果提升）。

## 完整回合流程（卡牌版）

```
═══════════════════════════════════════
         一个完整游戏回合（卡牌版）
═══════════════════════════════════════

[1] 抽牌阶段
    └─ 从抽牌堆抽 3 张 → 加入手牌

[2] Boss 行动阶段
    └─ Boss 掷 1d6
       1–3 → 甩尾横扫（第一排所有格受击）
       4–6 → 吐息攻击（选中某列全列受击）
       → 结算对玩家的伤害
       （可通过手牌中的「格挡牌」响应 Boss 行动）

[3] 玩家行动阶段
    └─ 从手牌中最多打出 2 张牌（依次结算）：
       ├─ 移动牌 → 立即移动
       ├─ 强化牌 → 增加本回合骰子/效果
       └─ 攻击牌 → 选择部位 → 掷骰 → 结算伤害

[4] 弃牌阶段
    └─ 剩余未打出的手牌进入弃牌堆

[5] 状态更新
    ├─ 检查四肢击破条
    ├─ 检查 Boss HP
    └─ 检查玩家 HP

```

## 大剑卡牌牌组示例

> 详细大剑武器说明见 [`weapons/greatsword.md`](./weapons/greatsword.md)

| 卡牌名称 | 类别 | 数量 | 效果 |
|----------|------|------|------|
| 普通斩击 | 攻击 | 4 | 掷 2d6 伤害；消耗 1 蓄力 |
| 蓄力 | 资源 | 3 | 获得 2 点蓄力，不可与攻击牌同回合使用 |
| 强斩 | 攻击 | 3 | 掷 3d6 伤害；消耗 2 蓄力 |
| 大力斩 | 特殊 | 2 | 掷 5d6 伤害；消耗 全部蓄力（至少 3）；此牌打出后本回合不能再打牌 |
| 看破 | 强化 | 2 | 本回合攻击目标弱点时额外 +2 骰子 |
| 侧步 | 移动 | 2 | 移动至任意相邻格，并获得 1 点蓄力 |

*大剑卡牌组机制核心：积累蓄力 → 释放高伤特殊牌*

## 战场与站位规则（同方向一）

参考 [`direction-1-turn-based.md`](./direction-1-turn-based.md)  
卡牌版使用相同的 3×3 网格与距离判定规则，移动可通过「移动牌」或保留移动阶段实现。

### 移动阶段（卡牌版调整）

- 若玩家在行动阶段打出移动牌，**可额外移动**（不占用基础移动阶段）
- 每回合仍保留一次免费移动机会（相邻一格）
- 移动阶段与打牌阶段相互独立

---

## 特殊机制：Boss 预告

为增加策略深度，卡牌版可在 Boss 行动前**预告其攻击类型**（翻出下回合 Boss 行动牌），  
让玩家提前用手牌进行针对性应对（如移动脱离、打出格挡牌）。

## Boss 部位 & 击破系统（同方向一）

| 部位 | 初始可攻击 | 击破后效果 |
|------|-----------|-----------|
| 头部 | ✅ | — |
| 四肢 | ✅（共享击破条） | 击破 → 解锁背部 & 尾部；Boss 倒地 2 回合 |
| 背部 | ❌（需四肢击破） | 高倍率部位 |
| 尾部 | ❌（需四肢击破） | 击破 → 横扫概率下降 |

## 方向二的优势 & 挑战

### 优势
- 手牌随机带来每局差异化体验，重复可玩性更高
- 卡牌组合创造 Synergy 感，玩家有「灵光一现」时刻
- 容易通过新卡牌扩展内容，长线更新友好
- 卡牌设计可反映武器武技特色，主题契合度高

### 挑战
- 开发复杂度更高（牌堆管理、状态机、UI 展示）
- 需要仔细平衡：过多强牌导致无聊，过少导致挫败感
- 手机竖屏下手牌 UI 布局设计需要精心安排
- 学习曲线略高，新玩家可能需要教程引导
